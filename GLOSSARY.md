# Sidekick

Sidekick turns a spoken or typed request into a task and brings the agent’s answer back to the person who asked.

**Destination** is the agent named in a request. Replicas runs work in a cloud workspace. T3 Code runs it in a thread in the selected local project.

**Finished answer** is the agent’s original response to a task. It can contain findings, completed work, or a question that needs the user’s input.

**Spoken summary** is Sidekick’s shorter rendering of a finished answer. The original stays available even when summary preparation fails.

**Task monitoring** means checking an existing task for progress, an answer, or confirmation that it stopped.
